# 生成提示词与制作方式

人物、头像、场景和重绘 UI 使用内置 ImageGen；每个资产分别生成。差分统一参考这次新设计的长发狮耳形象。纯底色为确定色值 #EAF5FA，无渐变。

UI 内为示例内容。文字作为 PNG 图像的一部分，若需自由更改文案，请在 PXD 里另放原生文字图层。
