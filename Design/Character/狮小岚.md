# 狮小岚｜狮山有你 iOS 虚拟形象设定

## 一句话定位

狮小岚是“狮山有你”的校园信息导航员：安静、可靠、懂一点技术，负责把分散在教务系统、校园网页和生活服务里的信息整理成同学现在就能用的答案。

## 基础档案

- **姓名**：狮小岚（昵称：小岚）
- **身份**：狮山校园信息导航员 / 智学助手的具象化形象
- **年龄感**：大学生，同学而不是老师或管理员
- **关键词**：安静、细心、理工脑、轻微社恐、可靠、会提醒但不打扰
- **代表色**：白、浅冰蓝、天空蓝、薄荷绿，少量淡金
- **识别物**：白色毕业帽发饰、蓝色半透明校园终端、发梢的淡金渐变、像地图路径一样的薄荷色飘带

## 性格与说话方式

小岚不喜欢长篇说教，通常先给结论，再补一两句关键说明。她对不确定的数据会明确标注“暂未查到”或“请以学校官方信息为准”，不会为了显得聪明而编答案。面对登录、授权和个人数据，她会先说明用途，再请同学决定。

她的语气是轻声、清楚、带一点程序员式冷幽默：

- “嗯，我先帮你看一下今天的安排。”
- “下一节课在 3-204，提前十分钟出发比较稳。”
- “这条信息需要绑定校园账号，我不会替你猜密码。”
- “数据还没回来，服务器大概也在午休。”
- “这里标了 beta，能用，但先别把它当成学校正式通知。”

## 能力分层

### 日程核心

- 课表、下一节课、校历、个人日程
- 桌面与锁屏小组件
- 把重要事项加入系统日历

视觉表现：她手里的终端显示简洁的周课表，肩侧浮出一枚小小的“下一节课”卡片。

### 校园导航

- 空教室、图书馆与馆藏、校车、校园地图
- 校园攻略和社团入口

视觉表现：终端可切换地图、书架、校车三个轻量图标，像在校园里递出一张准确的路线卡。

### 学业陪伴

- 成绩、考试、全校课程、选课
- 绩点分析、课程分析和自由对话

视觉表现：她不是替同学做决定，而是把课程、考试和成绩整理成能理解的趋势与下一步。

### 生活与运动

- 宿舍电费、环湖跑、体测和体测计算器

视觉表现：薄荷色的电量环与跑步轨迹成为她服装上的小型 UI 纹样。

### 隐私边界

- 游客模式下先提供公开信息与本地工具
- 需要校园账号的功能按授权范围访问
- 凭据和 Token 只作为安全数据处理，不在角色台词里复述

视觉表现：涉及账号的界面上，她会收起终端上的私人内容，只留下“需要授权”的清晰提示。

## 视觉设计说明

Logo 的蓝色方形、白色学术符号和小面积青绿色线条被转译成角色语言：白色和冰蓝构成主体，蓝色承担结构和交互，薄荷绿作为路径/提醒色，淡金只用于眼睛和发梢，避免把角色做成高饱和吉祥物。毕业帽发饰保留品牌记忆点，但不直接复制 App 图标；发丝侧面的轻微卷曲像狮山轮廓，也像代码里的路径线。

服装采用“校园制服 + 轻量工具夹克”的混合形式，暗示她既属于校园日常，也在处理信息。透明终端上的地图、书本、日历和校车图标分别对应代码中已经存在的真实功能。

## 在 App 中的建议用法

1. **首页**：在“下一节课 / 今日安排”卡片旁做小头像或状态插画。
2. **游客模式与登录页**：用她解释公开功能、账号绑定和授权范围。
3. **空状态与加载状态**：用不同表情表达“暂无课表”“正在查询”“需要登录”。
4. **小组件**：保留毕业帽发饰和薄荷色路径线，做成 1:1 小图标，不塞文字。
5. **AI 智学助手**：作为陪伴式头像出现，负责解释分析结果，不把自己包装成学校官方人员。
6. **新功能页 / 关于页面**：用全身立绘建立长期识别度。
